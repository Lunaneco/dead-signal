# DEAD SIGNAL

カメラの手認識で操作する、一人称の3Dブラウザゲーム。ゾンビサバイバルとバルーンラッシュを搭載。

[ブラウザで遊ぶ](https://lunaneco.github.io/dead-signal/)

## 起動

```sh
npm run dev
```

Node.js 22 以上を使用し、http://127.0.0.1:4387 を開きます。追加のnpm依存パッケージ・アカウント・サーバー用APIキーは不要です。カメラには HTTPS または localhost とブラウザの使用許可が必要です。マウス・タッチでも遊べます。

## 操作

- カメラでプレイを押すと手の認識モードへ移ります。左右どちらかの手全体を約1秒間認識すると自動で開始します。
- カメラ版では自分の左手も右手も銃に固定。左右を同時に操作でき、片手だけでも遊べます。画面の左右位置ではなく手の左右情報で割り当てるため、両手を交差しても銃の割り当ては変わりません。
- 左右それぞれ、人差し指を伸ばし、薬指と小指を曲げて約0.15秒キープすると、約0.25秒間隔で自動連射します。親指と中指は楽な位置に置いてください。構えを崩す・認識が途切れると、その側だけ停止します。
- リロード：装填したい側の手を、カメラに映したまま上下に1往復振ります。手を持ち上げて元に戻す、または下げて戻す動作に対応。「反対方向へ戻して装填」と出たら、そのまま戻してください。小さな揺れ・横振り・片方向だけの移動はリロードしません。左右に独立した12発の弾倉があり、装填は1.4秒。片方を装填中ももう片方で撃てます。
- 左右の残弾ボタンでその側をリロード。Rキーでは両方をリロード。Escは一時停止。
- マウス・タッチ版はクリック・タップした方向に銃を1発撃ちます。弾倉は12発で、Rキーまたは残弾ボタンでリロードします。
- ゾンビは通常型・高速型・耐久型・低姿勢型・奇行型の5種類。高速型は通常型の約2.5倍の基本速度、耐久型は体力8と2倍の接近ダメージ、低姿勢型は半分ほどの高さ、奇行型は左右への蛇行と急加速が特徴。市街の耐久型は頭2発、他は頭1発で撃退できます。後半のエリアでは耐久力が増加します。第1ウェーブで通常・高速・低姿勢・奇行、第2ウェーブで耐久型を紹介します。
- 通常ウェーブ突破で体力が15回復。WAVE 5・10・15… は専用ボス戦（ボス1体）です。ボスは64HPから始まり、ステージごとに24HP増加。頭への攻撃は3ダメージ。体力半分から暴走し、予兆を伴う突進と接近攻撃が強化されます。
- ボス撃破で体力100と両手の12発を補充し、4秒後に次のステージへ移動。隔離市街 → 灼熱製鉄所 → 汚染湿地 → 凍結研究施設の4エリアには、それぞれ専用背景・敵の名前と姿・大型ボスがあります。製鉄所の敵は加速、湿地は蛇行、研究施設は断続的な突進を加えます。
- 通算WAVEは継続します。4エリア突破後は変異した次の周回へ。ステージごとに敵の耐久力・速度・攻撃力・出現数が上昇し、出現間隔が短くなります。速度・同時出現数には操作性のため上限を設けていますが、耐久力は引き続き上がります。

左右の判定が不明確な手は攻撃せず、もう片方の確実に認識できる手を使い続けられます。両方とも約2.8秒見えなければ一時停止します。カメラ映像はブラウザ内で解析し、サーバーへ送りません。タイトル復帰・終了・ページ離脱時にカメラを停止します。

## 構成

HTML / CSS / JavaScriptだけで動く静的アプリです。共有ランキング・データベース・記録送信APIはありません。Three.js 0.170.0 と MediaPipe Tasks Vision 0.10.21、および hand_landmarker/float16/1 モデルを同梱。ゲームの街並み・ゾンビ・手は実際の3Dメッシュです。カメラの手は操作入力に使い、ゲーム内は一人称用の3Dハンドを表示します。手首が手前、指先が奥を向き、指の延長線を照準に合わせます。カメラ映像は認識確認用の小窓だけに表示します。手認識は最大2つの手を約20fpsで追跡します。検出された Left は左銃、Right は右銃へそのまま割り当てます。鏡表示のための反転はプレビューと照準の座標だけに適用し、左右のラベルは入れ替えません。認識配列の順序や画面上の位置には依存しません。直近の手の中心位置の履歴から上下移動と方向反転でリロードを検出します。手の大きさに応じた振り幅には上限を設け、250ms以内の一時的な認識抜けでは動作の履歴を維持します。各手の照準・弾倉・反動を独立して管理します。

手認識の実装資料：[MediaPipe Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)。

## バルーンラッシュ

制限時間60秒、延長込み最大120秒。通常100点、禁止−150点・−5秒、時間追加50点・＋5秒、巨大4発で500点、金色350点、高速200点。5連続で倍率が0.25ずつ上がり最大2倍。外す・撃つべき風船を逃す・禁止を撃つとコンボが切れます。バルーンは銃専用で、左右の照準・弾倉・リロードを共有せず操作できます。

## 自己ベスト

- ゾンビ／バルーン × カメラ／マウス・タッチの4区分で、最高得点だけを自動保存します。
- 保存先はこのブラウザの `localStorage`。ニックネーム・映像・手の座標・射撃ログは保存も送信もしません。
- 保存するのは得点、達成日時、到達WAVEや撃破数、バルーンの破裂数・最大コンボ・命中率です。名前入力やランキング送信ボタンはありません。
- 低い得点や同点で自己ベストを上書きしません。記録は端末間・ブラウザ間・異なるURLの公開先間では共有されません。
- ブラウザのサイトデータを消すと記録も消えます。保存が無効な環境では、その画面を開いている間だけの記録になり、画面にその旨を表示します。
- 自己ベストは個人の遊び用です。ブラウザから編集できるので、公的な競技記録や不正防止の保証には使用しません。

## 公開と開発

```sh
npm test
npm run build
npm run check:release
```

編集する原本は `dist/`。`npm run build` で公開する静的ファイルだけを `docs/` に複製します。GitHub Pages は `main` ブランチの `/docs` を公開する設定です。公開に認証情報やSecretsの登録は必要ありません。原本を変更したら、ビルドと検証をして `dist/` と `docs/` を一緒にコミットします。

モデル・JavaScript・WASM・フォントはすべて同梱し、同じ公開サイトから読み込みます。ゲーム独自の解析・広告・テレメトリ通信はありません。GitHub Pagesなどの配信サービス自体には、通常のアクセスログが残る場合があります。

ローカル開発サーバーは `127.0.0.1` のみに待ち受け、GET/HEADのみ許可します。公開用ディレクトリ外・ドットファイル・シンボリックリンクによる逸脱・旧ランキングAPIへのアクセスを拒否します。

セキュリティ確認範囲と制約は [SECURITY.md](SECURITY.md) を参照してください。ライブラリ・モデル・フォントの出典とライセンスは [THIRD_PARTY_NOTICES.md](dist/THIRD_PARTY_NOTICES.md) に記載しています。第三者のコードや素材にはそれぞれのライセンスが適用されます。

## BGM

全9曲を LUNA MUSIC のローカル ACE-Step 1.5 エンジンで、このゲーム用にインストゥルメンタルとして生成しています。タイトル、4エリア、ボス、バルーン、ステージクリア、ゲーム終了に合わせて切り替わります。戦闘曲はループ用に整え、場面変更ではフェードします。一時停止・別タブへの移動ではBGMも停止します。

ブラウザの制限により、最初のクリック／キー操作後に再生します。右上の音ボタンで効果音とBGMを消音でき、操作方法の「BGM音量」で曲だけの音量を調整できます。音源の読み込みに失敗してもゲームは続行できます。

配信するのは完成したMP3だけで、プレイヤーの端末で音楽モデルを実行したり、生成サービスへ通信したりしません。[曲ごとの生成条件・音声検査](dist/audio/manifest.json)を同梱しています。検査は全尺デコード・音量・ピーク・長さが対象で、自動検査による聴感の保証ではありません。
