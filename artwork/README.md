# DEAD SIGNAL — sharing artwork

Created on 2026-09-23 with Codex's built-in image generation tool (not the CLI). Both artworks were generated from text; no camera footage or personal images were used.

- `banner-original.png`: original wide key art. The web copy is `dist/assets/social-card-v1.jpg`, resized to 1200 × 630 and encoded as JPEG.
- `icon-original.png`: original square icon. PNG web copies are 512, 192, 180 and 32 pixels square under `dist/assets/`.
- Derivatives use only resizing and format conversion; the compositions are unchanged.
- The HTML contains Open Graph and Twitter large-image metadata with absolute public URLs. The icon is used for browser tabs, Apple home-screen bookmarks and the web app manifest.

## Banner prompt

Create a finished social sharing banner for the original Japanese browser game DEAD SIGNAL. Wide landscape aspect ratio 1.91:1, target 1200x630, edge-to-edge artwork. Premium stylized low-poly 3D arcade survival art, dark ink navy and foggy olive green with luminous acid lime accents (#c6ee76), crisp geometric forms, restrained cinematic light. Left 45% has very large beautifully typeset bold condensed off-white English title on TWO lines, exact text: DEAD SIGNAL. Small exact subtitle beneath: HAND-TRACKED SURVIVAL. Keep all letters fully inside generous 7% safe margins. Right 55%: first-person perspective of two bare stylized human hands emerging from the bottom corners, backs of hands toward viewer, both index fingers extended AWAY from camera toward a distant small group of low-poly zombies advancing down a ruined misty city street; each hand clearly makes a finger-gun gesture with thumb raised, other fingers curled. No held guns, no actual weapons. A sharp small lime muzzle spark emerges directly from an INDEX FINGERTIP, aimed downrange at zombies. Hands and fingers anatomically clean, five digits per hand, natural first-person orientation. Zombies are graphic non-gory silhouettes, recognizable and secondary to the hands/title. A small cluster of pink/cyan/gold round balloons near the far right edge subtly suggests the alternate balloon arcade mode. Cohesive professional game key art, high contrast, readable at thumbnail scale. No flames, magic, shurikens, logos of other brands, watermarks, extra text, UI frames, photographic faces, or gore. This is key art, not a screenshot mockup.

## Icon prompt

Create a finished square app icon for the original browser game DEAD SIGNAL. 1:1 square, target 1024x1024. Single highly legible centered graphic symbol: a stylized human hand making a finger-gun, index finger extending diagonally up-right toward a small four-point acid-lime muzzle spark, thumb raised, three remaining fingers curled naturally, five digits total. Clearly a BARE HAND, not a real gun. Chunky clean geometric low-poly silhouette, off-white knuckles and acid lime (#c6ee76) rim light, very dark ink-navy (#10182d) full-bleed background. Use the same premium geometric arcade survival art language as an original game called DEAD SIGNAL. Large simple silhouette occupies 70% of the canvas, ample 12% margin on all sides, clear at 32x32 pixels. Extremely minimal internal detail, bold contrast, polished precise contours. Tiny subtle circular aiming accent behind the hand is optional only if it strengthens clarity. Do not put any words, letters, title, border, rounded-square outer frame, real gun, magic, flames, shurikens, blood, photograph, or watermark. Opaque full square image suitable for app icons and favicons.
